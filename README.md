## 📋 Resumo das Etapas Realizadas

1. **Pesquisa e Clonagem do Template:**
   - Seleção do template `landy-react-template` desenvolvido em React e TypeScript.
   - Clonagem do repositório para o ambiente de desenvolvimento local.

2. **Configuração e Instalação de Dependências:**
   - Instalação dos pacotes e bibliotecas do projeto via `npm install`.
   - Verificação e gerenciamento das dependências do React (`npm ls react`).

3. **Desenvolvimento e Modificações:**
   - Alterações no código-fonte em `/src` (textos, componentes, estruturação e estilos).
   - Execução do ambiente local de desenvolvimento com `npm start`.

4. **Versionamento e Envio ao GitHub:**
   - Vinculação ao novo repositório remoto `https://github.com/nicollylemos/ProjetoGitTemplate.git`.
   - Commit e push na branch principal (`main`).

5. **Deploy e Hospedagem na Vercel:**
   - Importação do repositório no painel da Vercel.
   - Build e publicação contínua, assegurando o acesso público do projeto.

## 💻 Comandos Utilizados na Atividade

```bash
# 1. Clonar o repositório template original
git clone [https://github.com/Adrinlol/landy-react-template.git](https://github.com/Adrinlol/landy-react-template.git)
cd landy-react-template

# 2. Instalar as dependências do projeto
npm install

# 3. Verificar a árvore de dependências e versão do React
npm ls react

# 4. Iniciar o servidor local para testes e desenvolvimento
npm start

# 5. Configurar o novo repositório remoto e realizar o envio das alterações
git init
git remote add origin [https://github.com/nicollylemos/ProjetoGitTemplate.git](https://github.com/nicollylemos/ProjetoGitTemplate.git)
git branch -M main
git add .
git commit -m "Primeiro commit: projeto Landing Page Template"
git push -u origin main
